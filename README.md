# CLI Calculator (계산기)

Java 21 기반의 CLI 계산기입니다.

## 기능

- **지원 연산자**: 덧셈(+), 뺄셈(-), 곱셈(*), 나눗셈(/)
- **지원 숫자**: 모든 유리수 (정수 및 소수점 숫자)
- **입력 형식**: `숫자 연산자 숫자` (예: `10 + 5.5`, `3.5 * 4`)

## 빌드 요구사항

- Java 21 이상
- Maven 3.6 이상

## 빌드 방법

```bash
mvn clean compile
```

## 실행 방법

```bash
mvn exec:java
```

## 사용 예시

```
수식 입력: 10 + 5.5
결과: 15.5

수식 입력: 20 - 7.3
결과: 12.7

수식 입력: 3.5 * 4
결과: 14.0

수식 입력: 15 / 4
결과: 3.75

수식 입력: -10 + 5
결과: -5.0
```

종료하려면 `exit` 또는 `quit`를 입력하세요.
